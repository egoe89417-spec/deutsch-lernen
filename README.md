# Deutsch Lernen — Telegram Mini App

Это именно Telegram Mini App: бот открывает веб-приложение внутри Telegram.

## Локальный запуск

1. Установи Python 3.11+.
2. В PowerShell:
   `py -m pip install -r requirements.txt`
3. Скопируй `.env.example` в `.env`.
4. В `.env` укажи токен бота.
5. Для Telegram нужен HTTPS URL. Для теста можно использовать туннель (например, Cloudflare Tunnel/ngrok) и указать его HTTPS-адрес в `WEBAPP_URL`.
6. Запусти:
   `py run.py`

## Важно

`WEBAPP_URL` должен указывать на адрес, где доступна эта папка приложения по HTTPS. Например:
`https://example.example`

После этого отправь `/start` своему Telegram-боту и нажми кнопку «Открыть Deutsch Lernen».

## Функции

- Telegram Mini App интерфейс
- добавление слов
- перевод
- примеры
- фотографирование/выбор фото на телефоне
- сохранение фото на сервере
- словарь
- повторение
- проверка ответа
- статистика правильных/неправильных ответов
- SQLite база данных

Для боевой версии стоит дополнительно включить проверку Telegram WebApp initData на сервере и автоматическую генерацию переводов/примеров.
